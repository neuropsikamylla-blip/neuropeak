# Nomenclatura dos exercícios

Os IDs internos são chaves técnicas estáveis. Os nomes oficiais descrevem o treino que a pessoa faz
e são os únicos usados na interface e na documentação clínica.

## Casos registrados

### Cubos

ID técnico: `cubo-corsi`. Não usamos “Corsi”: é nome de **teste neuropsicológico padronizado**, e o
aplicativo é de **treinamento** cognitivo, não de avaliação.

### Cores e Palavras

ID técnico: `stroop-task`. Não usamos “Stroop” pelo mesmo motivo: trata-se de nome associado a teste
neuropsicológico padronizado, enquanto o aplicativo oferece treinamento, não avaliação.

### Alternância de Regras

ID técnico: `task-switching`. O paradigma científico chama-se Task Switching, mas o que o paciente
executa é a **alternância das regras de resposta**. O nome oficial descreve o treino, não o
paradigma.

### Agentes Focus

ID técnico: `focus-agents`. Mantém “Focus” como identidade do exercício; a nomenclatura oficial é
**Agentes Focus**.

## Regra geral

Nome de teste padronizado nunca aparece para o paciente, porque carrega expectativa de medida
diagnóstica.
